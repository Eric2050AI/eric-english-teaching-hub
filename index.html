数据备份

所有数据都保存在这台电脑的浏览器里，请定期导出备份，避免清理浏览器时丢失

📊 当前数据概览

⬇ 导出备份

把学生档案、班级、日历排课、课堂登记、成长分析编辑内容以及你自定义过的所有选项， 一次性打包成一个 JSON 文件保存到电脑上。建议每周导出一次，或在每次录入大量数据后导出。
✓ 已导出，请把文件保存到你放心的位置（如网盘、U盘）。

⬆ 导入备份

选择之前导出的 JSON 备份文件恢复数据。导入时可以选择「合并」（保留现有数据，同一条记录以备份为准） 或「完全替换」（清空现有数据后导入）。换电脑或重装浏览器后，用这个功能即可恢复。
💡 建议：导入前先做一次导出，万一导错了还能退回来。

⚠️ 清空所有数据

删除这台电脑上保存的全部数据（学生、班级、排课、课堂登记、成长分析）。 此操作不可恢复，仅在你确定已经导出备份、或想彻底重新开始时使用。
